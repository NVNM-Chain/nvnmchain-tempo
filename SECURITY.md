# Security

Report a vulnerability privately, not in a public issue or pull request:

- through [GitHub's private vulnerability reporting](https://github.com/NVNM-Chain/nvnmchain-tempo/security/advisories/new), or
- by email to [security@nvnmchain.io](mailto:security@nvnmchain.io).

Say which version or commit is affected, what the flaw allows and how to reproduce it.
